INSTALLATION INSTRUCTIONS:
1. Transfer 'ATTENDLY.apk' to your Android smartphone or tablet (via USB Cable, Google Drive, WhatsApp, or Bluetooth).
2. Open the file manager on your Android device and tap on 'ATTENDLY.apk'.
3. If prompted by Android Security, enable "Install unknown apps" or "Allow from this source" for your file manager or browser.
4. Tap "Install" and open "ATTENDLY". Upgrading over an older install keeps your data.

MINIMUM REQUIREMENTS:
- Android OS: Android 7.0 (API Level 24) or higher
- Recommended: Android 10, 11, 12, 13, 14, 15, or 16
- Architecture: Universal (Supports arm64-v8a, armeabi-v7a, x86_64)
- Internet: Not required for core operations. Full offline functionality with persistent local storage.

KEY FEATURES ON ANDROID:
- Mobile-first responsive UI with bottom navigation (Home, Log, Timetable, More).
- Touch-optimized controls and safe-area insets for notched and hole-punch displays.
- Integrated Android Hardware Back Button navigation.
- 4-State Attendance Logger (Present, Absent, Cancelled, Shifted / Swapped).
- Dual-Rule Detention Alert Engine (Overall < 75% or any Course < 60%).
- Smart What-If Simulator with live projected attendance and recovery advice.
- Weekly Timetable Matrix with Effective Date versioning.
- Monthly Academic Calendar and past unlogged day resolution.
- Offline LocalStorage persistence and portable JSON Backup Export/Import.
